*정보 이용 탐색이란?* A. 이전 경험이나 지식을 바탕으로 탐색하는 방법이다.
- 정보 이용 탐색은 비슷한 문제에 대한 이전 경험이나 지식을 바탕으로 어떤 기준을 판단하여 결정하는 탐색 방법
- 이때 만들어진 정보를 휴리스틱 정보라고 하여 이를 휴릿틱 탐색이라고도 함.
- 문제의 해가 정확하게 나오지 않을때 또는 정해진 시간 안에 모든 탐색을 완료하지 못할 때 아주 유용함

*언덕 등반 탐색(HCS)* p.36
- 현재 지점에서 경험에 의한 평가 함숫값이 가장 좋은 주변 지점을 하나씩 선택해서 확장해 나가는 탐색 방법
- 그리디 알고리즘 이라고도 불림(greedy algorithm)
- 지역적으로도 최적의 해이면서 전체적으로도 최적의 해를 찾는 문제에 적합함
- 같은 수면 왼쪽 먼저
- 탐색 과정 : 제시한 초기 상태를 오른쪽의 목표 상태로 만드는 것이 문제라고 할 때, 목표 위치에 있는 퍼즐의 개수를 평가 함수로 생각할 수 있다. 이때 목표 위치에 있는 퍼즐의 개수를 점수로 하여 언덕 등반 탐색을 진행한다.

-> 트리가 적을수록 효율적

*최상우선탐색(BFS : Best First Search)*
- 최적 우선 탐색 또는 최고 우선 탐색이라고 부름
- 언덕 등반 탐색을 개선한 탐색 알고리즘으로 평가 함수와 open, close 리스트를 사용하여 리스트 안에 있는 요소 중 가장 유리한 것을 선택함.
- 언덕 등반 탐색은 한 번 선택되면 같은 레벨의 다른 노드는 선택에서 고려하지 않지만, 최상 우선 탐색은 선택되지 못한 노드도 다시 고려하는 과정을 거침
- HCS + 1가지 더 고려
- 다시 돌아가는 경우도 고려하기

- *A*알고리즘*
- A*알고리즘은 기본적으로 최상우선탐색과 유사함
- 다만, 과거+현재 값 계산
