# 2026.08.26. 4교시

*정보 이용 탐색이란?*
- 휴리스틱 탐색 또는 경험적 탐색이라고도 함.
- 상태 공간에 관한 정보를 활용하여 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있음
- 정보 이용 탐색 방법 : 언덕 등반 탐색, 최상우선탐색, A*알고리즘

[탐색 -> 맹목적 / 정보 이용 탐색 -> 언덕 등반 탐색, 최상우선타색, A*알고리즘]

*맹목적 탐색은 무엇일까?*
A : 상태 공간에 관한 정보 없이 탐색하는 방법이다.

- 상태 공간(노드)에 관한 정보 없이 기계적인 순서(=규칙)로 모든 상태를 탐색하는 방법
- 분기점에서 어떤 순서로 분기할지 미리 정해 두고 탐색함

*깊이 우선 탐색(D(Deep)FS)* : 한 개의 노드를 선택하여 깊게 탐색한 후, 다시 상위로 돌라와 같은 방법으로 깊게 탐색

- 탐색 트리에서 갈 수 있는 길이 있는 한 앞으로 계속 전진하여 탐색하는 방법 => 한칸씩
- 분기점에도착했을 때 방문하지 않은 곳을 선택하여 앞으로 나아가는 과정으로 반복
- 오름차순/ㄱㄴㄷ순/ABC순/ 낮은 것(왼쪽부터)부터 오도록 & 밑으로 먼저 갔다가 옆으로 가기
